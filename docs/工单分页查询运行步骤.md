# 工单多条件分页查询运行步骤

## 1. 准备环境

- Java 21
- Maven Wrapper（项目自带 `mvnw.cmd`）
- MySQL 8.0+
- 数据库连接默认使用 `localhost:3307`、数据库 `bag_mes`、用户 `root`、空密码；也可以通过 `MES_DB_PORT`、`MES_DB_USERNAME`、`MES_DB_PASSWORD` 覆盖。

## 2. 初始化数据库和演示数据

先执行 `src/main/resources/db/bag_mes_schema.sql` 创建数据库及核心表，再执行 `src/main/resources/db/work_order_demo.sql` 写入 3 条工单演示数据。

## 3. 启动项目

在项目根目录执行：

```powershell
./mvnw.cmd spring-boot:run
```

服务启动后访问 `http://localhost:8090`。

## 4. API 测试

接口：`GET /work-orders/page`

测试组合一：

```text
http://localhost:8090/work-orders/page?pageNum=1&pageSize=10&status=RELEASED&priority=2
```

预期返回 `HTTP 200`，`data.total=1`，工单号为 `WO20260901`。

测试组合二：

```text
http://localhost:8090/work-orders/page?pageNum=1&pageSize=10&status=RUNNING&skuId=1
```

预期返回 `HTTP 200`，`data.total=1`，工单号为 `WO20260902`。

## 5. 自动化验证

```powershell
./mvnw.cmd -Dtest=WorkOrderPageQueryIntegrationTest test
```

该测试启动 Spring Boot、连接真实 MySQL，并验证上述两种条件组合的分页查询。
