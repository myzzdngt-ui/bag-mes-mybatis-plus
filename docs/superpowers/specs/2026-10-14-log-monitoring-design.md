# 箱包 MES 日志方案修订设计

## 目标与范围

依据分组任务14，在任务10已完成的箱包 MES 日志设计基础上，取消 `@LogMonitor` 和 `LogMonitorAspect` 的 AOP 自动采集；项目运行日志统一使用 SLF4J API 与 Logback 输出。交付更新后的日志设计 Word、自动化测试方案 Word、代码配置和 Git 提交记录。

数据库 `operation_log`、`api_monitor_log` 两张表、MyBatis-Plus 查询服务和分页接口继续保留，以支持查看任务10既有记录和演示数据。任务14的新运行日志不再自动写入这两张表，输出目的地为控制台和滚动文件。

## 方案比较与选择

| 方案 | 优点 | 限制 |
|---|---|---|
| 任务10自定义 AOP 写数据库 | 横切逻辑集中；日志可以按字段查询；适合数据库审计 | 依赖切面与注解；日志写入和业务数据库耦合；逐次请求写库增加开销 |
| SLF4J + Logback | 业务代码主动记录事件；级别过滤、格式控制和滚动归档由框架提供；容易接入文件采集工具 | 默认是文件/控制台日志，查询分析要使用日志平台或另建索引；不能替代结构化数据库审计 |
| 外部 APM/集中日志平台 | 可聚合检索与告警，分布式可观测性强 | 依赖外部服务和部署，本次课程项目不具备必要条件 |

最终选择 SLF4J + Logback 作为项目运行日志方案，符合任务14指定技术并降低对 AOP 的依赖。任务10数据库日志表留作独立审计数据存储和历史查询能力，不与运行日志混称。

## 实现组件

- `spring-boot-starter-logging` 提供 SLF4J、Logback Classic/Core。
- `logback-spring.xml` 同时配置控制台和 `logs/bag-mes.log` 文件输出；日志每天滚动，单文件超过10MB切分压缩，保留30天，总量限制1GB。
- `RequestTraceLoggingFilter` 为每个 HTTP 请求生成 UUID，写入 MDC 的 `traceId`，通过 `X-Trace-Id` 响应头回传，并在请求结束时清理 MDC。
- `WorkOrderServiceImpl` 使用 `LoggerFactory` 记录工单分页查询开始、成功和异常；过滤条件只记录安全的状态/优先级与分页信息。
- HTTP 过滤器记录 method、无查询参数的 path、状态码和耗时；超过 `mes.monitor.slow-threshold-ms`（默认1000ms）输出 WARN，异常输出 ERROR。
- AOP 依赖、`@LogMonitor` 注解和 `LogMonitorAspect` 已从项目移除。

## 日志等级定义

| 级别 | 规则 | MES 示例 |
|---|---|---|
| ERROR | 当前请求或业务操作失败，需人工处理；包含异常堆栈 | 数据库异常、关键业务处理失败 |
| WARN | 请求慢、输入/状态异常或服务降级，但系统可继续工作 | HTTP耗时达到阈值、HTTP状态码为4xx/5xx |
| INFO | 业务关键步骤、请求完成和系统启停 | 工单分页完成、请求状态和耗时 |
| DEBUG | 本地调试用细节，生产默认关闭 | 工单分页条件与分页号 |
| TRACE | 极细粒度诊断，默认关闭且只在短时排障开启 | 方法级追踪细节 |

## 日志内容规范

每条记录按时间、级别、线程、traceId、Logger名称、消息输出。使用 SLF4J 参数化占位符，避免字符串拼接。异常对象作为最后一个参数传入以保留堆栈。请求URI不含查询串；只记录必要业务标识和摘要。

禁止记录密码、令牌、密钥、Cookie、Authorization、完整请求体、完整SQL参数和不必要的个人信息。DEBUG/TRACE不能成为绕过脱敏规则的途径。日志只用于排障、审计和性能分析，按30天滚动保留，日志目录加入 `.gitignore`，不提交运行日志。

## 关联关系和数据库日志表边界

日志表ER关系沿用任务10设计：产品SKU与工单为一对多，工单与报工明细为一对多；`operation_log` 和 `api_monitor_log` 通过 `trace_id` 逻辑关联。SLF4J 文件日志中的 MDC `traceId` 关联同一次 HTTP 请求内的过滤器与业务服务日志。两种存储方式相互独立，任务14不自动插入新数据库日志记录。

## 测试范围

单元测试覆盖过滤器 traceId 生成/响应头/MDC 清理、HTTP成功异常和慢请求分支、工单服务的正常结果及异常堆栈日志、级别与敏感信息规范。接口测试覆盖工单分页成功响应、参数边界、4xx/5xx、响应 traceId 与日志文件同 traceId 关联。集成测试验证数据库两张日志表和分页查询接口仍可使用，不要求任务14运行日志自动入库。

测试详细用例、覆盖标准、执行步骤和自动化实施方案见《箱包MES自动化测试方案》。

## 验收标准

1. POM 含 SLF4J/Logback 依赖且不再依赖 Spring AOP starter。
2. 应用启动后控制台和日志文件均能看到格式化记录，含 traceId。
3. 工单查询能记录 INFO 完成日志；查询异常记录 ERROR 堆栈；超时或非成功状态记录 WARN。
4. 日志中不存在完整查询串、凭据或请求正文。
5. 任务10数据库日志分页接口及已有数据库记录仍可查询。
6. 仓库新增任务14分支和提交记录截图，提交两份 Word 设计文档。
